House Prices v6 最终方案

0.11212

最终采用的 Kaggle 线上 log-RMSE，越低越好。成绩由用户反馈，未通过 Kaggle 接口独立读取；较 v5 降低 3.30%，较首版降低 6.32%。

最终采用 v6：将已有传统模型集成与两种 TabPFN 特征表示组合，以不同预测方向的互补性降低误差。模型和提交文件保持 v6.0.0 原样；v6.1.0 补充实测成绩、报告和分享说明。

最终模型

1/3 v5 + 1/3 住宅结构特征 TabPFN + 1/3 质量类别特征 TabPFN
log(price) = (z_v5 + z_physical + z_quality) / 3
最后 exp 转回房价，等价于三路价格的几何平均。

v5 复用既有 ElasticNet、CatBoost 与 SVR 集成。physical 在原始字段上构造总面积、房龄、浴室、质量交互等共 112 列，使用 16 个内部成员。quality 保留原始 79 列，将 OverallQual/OverallCond 当类别处理，使用 4 个内部成员。两路在最终结果中各占 1/3，权重不按内部成员数量分配。

使用官方公开 TabPFN v2 回归权重，Python 包版本 tabpfn 9.2.0；固定 revision、checkpoint SHA-256、训练上下文与随机种子。Id 与 SalePrice 不作输入特征，MSSubClass 当类别，预处理在各折训练部分拟合。

选择依据与局限

在粗权重比较之外，采用自然三路等权。其普通房屋和 Normal 误差优于 50%/75% TabPFN 权重。75% 虽总体更低，对半权方案的新增收益约 96.9% 来自两套极端房屋，因此未作最终提交。相对原 v5，各组去除最大五笔正收益后普通/Normal 仍有净收益；调权增量仍集中，不能保证每一组都改善。线上最终为 0.11212，之后停止优化。
